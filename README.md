# 조현범 · 권주영의 모바일 청첩장

주영님이 직접 사진·예식 정보·계좌·디자인을 바꾸는 모바일 청첩장입니다. 무료 GitHub Pages 주소를 사용하고, Supabase 무료 요금제로 사진과 공개 내용을 저장합니다. 유료 도메인은 사용하지 않습니다.

- **청첩장:** https://ka8877.github.io/ju_wedding/
- **관리 페이지:** https://ka8877.github.io/ju_wedding/#/admin

Supabase 공개 연결값은 코드에 등록돼 있습니다. 실제 SQL·관리자 계정 준비와 연결 검증은 별도로 필요하며, 설정값 등록만으로 사진 저장이나 로그인 검증이 완료되는 것은 아닙니다.

## 두 개의 화면

- **청첩장:** 사이트의 기본 주소. 공개한 내용만 하객에게 표시합니다.
- **관리 페이지:** 기본 주소 뒤에 `#/admin`. 사진, 기본 정보, 예식 장소, 계좌, 디자인을 편집하고 미리 본 뒤 공개합니다.

예식 날짜·장소·계좌·사진은 비워 두었습니다. 알려지지 않은 결혼 정보를 임의로 넣지 않았습니다.

## 두 분이 직접 고르는 디자인

- **6가지 레이아웃:** 보태니컬 가든, 에디토리얼, 시네마틱 러브, 타임리스 클래식, 그레이스 채플, 디어 마이 러브
- **9가지 색감**과 직접 고르는 포인트 색상, 3가지 글꼴과 글자 크기
- 첫 화면 제목·사진 모양·사진 위치·갤러리 배치·장식 표시
- 섹션 순서·표시 여부·제목, 초대 문구 추천과 직접 작성
- 성경 말씀 추천·내용 수정, 직접 쓰는 축복 기도
- 실행 취소·다시 실행, 전체 청첩장 백업·가져오기

템플릿을 바꿔도 두 분의 사진·이름·장소·계좌와 직접 쓴 문구는 유지됩니다. 기존 버전에서 저장한 초안도 새 디자인 기본값을 채워 불러옵니다.

## 개발

Node.js 24 LTS를 사용합니다.

```bash
cd /workspace/ju_wedding
npm ci
npm run dev
```

```bash
npm test
npm run test:db
npm run build
npm run test:e2e
```

`test:db`는 메모리에서 실행되는 실제 PostgreSQL(PGlite)로 SQL·RLS 정책 17개를 검사합니다. Supabase의 인증·저장소 스키마만 모의 구성하며, 익명 조회 제한·일반 사용자 쓰기 차단·관리자 권한·초안과 공개 내용 분리·마이그레이션 재실행을 확인합니다. 실제 Supabase Auth 로그인, Storage API의 파일 형식·용량 검사, CDN 전송은 프로젝트를 연결한 뒤 별도로 검증해야 합니다. 테스트에는 클라우드 연결이나 비밀 키가 필요 없습니다.

이 프로젝트의 기존 체크아웃을 사용하세요. 클라우드 작업은 이미 격리돼 있으므로 별도 Git worktree는 필요하지 않습니다.

## 실제 공개 사이트로 연결하기

**[초기 연결 안내](docs/SETUP.md)**에 준비된 무료 Supabase 프로젝트의 SQL 실행, 주영님 계정 등록, 읽기 전용 연결 점검을 정리했습니다. 공개 연결값이 코드에 있어 GitHub 변수를 따로 등록하지 않아도 됩니다. `main` 코드 변경은 자동 배포되고, 주영님의 사진·문구 변경은 관리 페이지에서 공개하므로 GitHub를 열 필요가 없습니다.

`npm run check:connection`은 기본 공개 설정(또는 환경 변수·`.env.local` 덮어쓰기)으로 실제 공개 조회와 익명 접근 제한, 사진 버킷 경로를 읽기 전용으로 확인합니다. 관리자 로그인과 실제 업로드 검사는 별도로 필요합니다. secret/service-role 키는 사용하지 않습니다.

로컬 미리보기 모드의 수정은 다른 기기나 하객의 청첩장에 전달되지 않습니다. 실제 사진 저장과 공개 내용 변경은 준비된 Supabase 프로젝트를 사용합니다.

연결 후에는 관리자가 **임시 저장 → 미리보기 → 공개** 순서로 작업합니다. 디자인 코드 변경은 `main`에 반영할 때 GitHub Actions가 검사 후 다시 배포하며, 사진과 문구 변경은 관리 페이지에서 처리하므로 코드 배포가 필요 없습니다.

## 공개 범위

- 청첩장에 공개한 문구·사진·계좌번호는 링크를 아는 사람이 읽을 수 있습니다.
- 사진은 공개 저장 버킷을 사용합니다. **업로드한 파일은 최종 공개 전에도 파일 주소를 아는 사람이 볼 수 있으므로**, 공개해도 되는 사진만 올리세요.
- 관리자 계정은 Supabase Auth로 인증하고 데이터베이스·사진 쓰기 권한은 관리자 목록으로 제한합니다. 회원가입만으로 관리 권한이 생기지 않습니다.
- 프런트엔드에는 공개용 키만 사용합니다. `service_role` / secret 키와 관리자 비밀번호는 GitHub 저장소나 클라이언트 코드에 넣지 않습니다.
- 사진은 JPG, PNG, WebP, AVIF, 파일당 최대 8 MiB입니다. 휴대폰의 HEIC 사진은 JPG로 변환해서 올리세요.

장소 지도는 OpenStreetMap을, 장소 검색은 Nominatim을 사용합니다. 검색이 불가능한 경우 주소와 좌표를 직접 입력할 수 있으며, 네이버·카카오 지도에서 길찾기도 열 수 있습니다. 지도 제공 서비스의 응답과 데이터 범위는 해당 서비스에 따릅니다.
